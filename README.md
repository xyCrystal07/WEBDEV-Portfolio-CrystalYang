# WEBDEV Portfolio - Crystal Yang

This is my personal web development portfolio website. The project was created to showcase my work, web development skills, design process, and understanding of accessibility and global goals.

## About the Project

This portfolio was built using HTML, CSS, and JavaScript. It includes multiple pages that introduce my projects and demonstrate different aspects of the web development process.

The website focuses on creating a clear, accessible, and interactive user experience while allowing me to practice front-end web development skills.

## Pages

- **Home** - Introduces me and highlights my HTML, CSS, and JavaScript skills.
- **Portfolio** - Showcases some of my work, including my hobbies, travel experiences, and an advertisement project.
- **Design Process** - Documents my design thinking process from research and ideation to prototyping and testing.
- **Global Goals** - Explores UN Sustainable Development Goal 4: Quality Education and how web development can contribute to education.
- **Accessibility** - Discusses accessibility considerations used when designing the website.
- **Behind the Curtain** - Provides additional information about the development of the website.

## Design Process

I followed a design thinking process while developing the portfolio:

1. **Empathize** - Researched web developer portfolio examples to understand common layouts and user expectations.
2. **Define** - Identified the main content, pages, and features needed for the website.
3. **Ideate** - Created a wireframe and considered different layouts and navigation structures.
4. **Prototype** - Built the initial HTML structure before adding CSS styling and interactive features.
5. **Test** - Tested navigation, content, and interactive elements and made improvements based on the results.

## Running the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Use the navigation bar to explore the different sections of the portfolio.

## Large Media Files

The advertisement video in this project is managed using Git Large File Storage (Git LFS).

If you clone the repository and need the video file, make sure Git LFS is installed.
