Reflection

To tell the truth, it might be the most difficult task I met in the Computer Science Course learning. However, developing this portfolio website has been an incredibly valuable learning experience that allowed me to apply and expand my web development skills. I wrote the code step by step and built the website. Throughout the process, Visual Studio Code give me much help. By learning knowledge and exercising, I created a professional, accessible, and responsive showcase of my abilities. I began by thoroughly analyzing the project requirements and applying design thinking principles. The ideation process led to multiple wireframes and style concepts before settling on a clean, professional design with a blue and red color scheme for visual appeal and accessibility. One of the most frustrating challenges I encountered was linking my portfolio.html to index.html. Despite multiple attempts, the navigation simply wouldn’t work—clicking the "Portfolio" link in the header did nothing, or worse, led to a 404 error. At first, I thought it was a simple file path issue, but after checking and rechecking, the problem persisted. I spent hours debugging, trying different approaches: A)Absolute vs. Relative Paths – Initially, I used href="/portfolio.html", which failed because my local development environment didn’t recognize the root directory. Switching to href="portfolio.html" (relative path) B)Case Sensitivity – I discovered that some systems (like GitHub Pages) treat filenames as case-sensitive. My file was named Portfolio.html, but the link used portfolio.html, causing a mismatch. C)Browser Cache Issues – Sometimes, old cached versions of the page interfered, so I had to hard-refresh (Ctrl+F5) to see changes. This experience taught me the importance of precise file referencing and how small oversights can lead to major roadblocks. Another significant challenge was implementing the project filtering system in the portfolio section. I solved this by using data attributes and event delegation in JavaScript, which proved more efficient than individual event listeners. The mobile navigation menu required careful attention to accessibility, particularly ensuring proper keyboard navigation and ARIA attributes. Creating the "Behind the Scenes" tabs helped me better understand DOM manipulation and state management in vanilla JavaScript. This project has been instrumental in developing my skills and confidence as a web developer. It pushed me to find solutions independently while also recognizing when to seek help. Seeing my progress from initial struggles to a fully functional portfolio has been incredibly rewarding. The experience has motivated me to continue learning and improving, with plans to expand this portfolio as I tackle more advanced projects in the future.
